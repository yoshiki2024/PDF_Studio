# PDF_Studio

ビジネスパーソンのための、**「完全ローカル・安心安全・インストール不要」**な高機能PDF加工・編集ツールです。  
直感的で洗練されたUIにより、PDFの結合・分解・向きの変更・テキスト編集をスムーズに行えます。

---

## 🔒 3つの大きな安心・特徴

1. **100% ローカル（ブラウザ内）完結処理**
   - アップロードされたPDFデータは、お使いのパソコンのブラウザ内（WebAssembly / JavaScript）でのみ処理されます。
   - 外部サーバーへの通信は一切発生しないため、**請求書・領収書・決算書・契約書・個人情報などの機密書類でも安心**してご利用いただけます。
2. **非破壊保存の安全設計**
   - 元のPDFファイルを上書きすることは一切ありません。すべての処理結果は新しいPDFファイルとして安全に書き出されます。
3. **インストール・環境構築が一切不要（Windows & Mac 両対応）**
   - 面倒な専用ソフトウェアのインストールや、Python / Node.js などの専門的な環境構築は必要ありません。
   - フォルダ内の `index.html` をダブルクリックするだけで即座に起動します。

## 👥 第三者に渡して使ってもらう方法（共有・配布ガイド）

### Q. Gitからダウンロードすれば相手もすぐに使えますか？
**A. はい、ダウンロードしてすぐに使えます！**  
特別なランタイムやサーバー、ライブラリの事前インストールは一切不要です。ダウンロードしたフォルダを開き、ブラウザで開くだけで即座に動作します。

### Q. Windows以外（Macなど）でも使えますか？
**A. はい、MacでもWindowsと全く同じように動作します！**  
Google Chrome、Microsoft Edge、Safari などのモダンブラウザさえあれば、OSを問わず軽快に動作します。

### 配布・共有のやり方（3つの方法）

#### 【方法1】ZIPファイルで渡す（最もシンプル・おすすめ）
1. GitHubリポジトリ（[https://github.com/yoshiki2024/PDF_Studio](https://github.com/yoshiki2024/PDF_Studio)）右上の緑色の **`Code`** ボタンをクリックし、**`Download ZIP`** を選択します。
2. ダウンロードされたZIPファイルを展開（解凍）します。
3. 展開したフォルダ内の **`index.html`** をダブルクリックして開くだけでツールが起動します！
   - ※相手にメールや社内チャット、共有フォルダでZIPファイルをそのまま渡すだけで利用可能です。

#### 【方法2】GitHub PagesでWebサイトとして共有する（相手にダウンロードさせない方法）
相手にファイルをダウンロードさせず、URLをクリックするだけで使わせたい場合は、GitHub Pagesの利用が最も便利です：
1. GitHubの `PDF_Studio` リポジトリの **`Settings`** タブを開きます。
2. 左メニューの **`Pages`** を選択します。
3. **`Build and deployment`** の Branch を `main` / `/(root)` に設定して **`Save`** を押します。
4. 数分で専用URL（例: `https://yoshiki2024.github.io/PDF_Studio/`）が発行されます。
5. このURLを相手に送るだけで、相手はブラウザを開くだけでツールを利用できます（Web上に公開しても、処理自体は各ユーザーのブラウザ内ローカルで完結するため機密保持性は保たれます）。

#### 【方法3】Git Clone を使う（開発者向け）
ターミナル（Mac）または PowerShell / コマンドプロンプト（Windows）で以下を実行：
```bash
git clone https://github.com/yoshiki2024/PDF_Studio.git
cd PDF_Studio
# Windowsの場合
start index.html
# Macの場合
open index.html
```

#### 【方法4】Google Chrome拡張機能（アドオン）として導入する（超便利・おすすめ！）
ブラウザのツールバーにピン留めしておけば、いつでもアイコンを1クリックするだけで新しいタブでPDF Studioが立ち上がります：
1. Google Chrome を開き、アドレスバーに `chrome://extensions` と入力して開きます。
2. 画面右上にある **「デベロッパー モード」** のトグルスイッチを **ON** にします。
3. 画面左上に出現する **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
4. 本ツールのフォルダ（`index.html` や `manifest.json` が入っているフォルダ）を選択します。
5. Chromeのツールバーのパズルピースアイコン（拡張機能メニュー）から **「PDF Studio」** のピン留めアイコンをクリックして固定します。
6. 以後は、ブラウザ右上の **📑 アイコン** をクリックするだけで、即座に新しいタブでPDF Studioが開きます！

## 🚀 主な機能と使い方

### 1. 📂 ホーム画面（ドラッグ＆ドロップ）
- 画面中央のドロップゾーンにPDFファイルをドロップ（複数ファイル同時対応）。
- 読み込まれたファイル一覧から操作したいものをチェックして、実行したい機能カードをクリックします。
  - **PDF編集 / PDF分解 / 向きの変更**：1ファイルを選択して実行
  - **PDF結合**：2ファイル以上を選択して実行

---

### 2. ✏️ PDF編集（テキスト修正・ハイライト・墨消し・画像挿入）
- **文字選択・テキスト直接打ち替え＆フォント自動判別**:
  - プレビュー上の文字をクリックすると選択状態になり、左側パネルで文字の修正、フォントサイズ変更（スライダー）、カラー変更、太字・斜体への切り替えが可能です。
  - プレビュー上で直接文字を**ダブルクリック**してインライン編集状態に入る際、**元テキストのフォント（游ゴシック、メイリオ、ＭＳ Ｐゴシック、明朝体、Arial等）や太字・斜体を自動判別し、同一フォントをデフォルト選択**します。フォントを手動で選び直す手間なく、自然な仕上がりで修正できます。
  - 移動させたい文字をドラッグすると、元の位置にある文字が自動で白塗り消去され、移動先の文字と二重に表示されることなくスムーズに移動できます。
- **PDF埋め込み画像・ロゴの移動＆消去**:
  - PDF内に元から埋め込まれている企業のロゴマーク、図表、社印、写真などの画像を自動検出して枠線表示（「画像/ロゴ」バッジ付き）。
  - **移動**: 対象の画像をマウスで直接ドラッグするだけで、元の位置は自動で白塗り消去され、自由な位置へスムーズに配置し直せます（リサイズハンドルで拡大縮小も可能）。
  - **消去**: 画像右上の「×」ボタンを押すか、画像を選択してキーボードの `Delete` / `Backspace` キーを押すだけで、原本PDFを傷つけずに白塗りで綺麗に消去できます。
- **文字ドラッグ選択式ハイライト（蛍光マーカー）**:
  - マウスでドラッグして対象の文字を選択（背景色と文字色が反転）し、サイドバーの「選択した文字をハイライト」ボタン、または選択直後に現れるクイックツールバーを押すだけで、選択した文字だけにピッタリとハイライトが適用されます。
  - ハイライトは**テキストの背面レイヤー**に自動配置されるため、文字が蛍光色に埋もれることなくくっきりと読めます。
  - カラーパレット（イエロー、グリーン、ピンク、ブルー）で色を自由に変更可能です。
- **墨消し・白塗り（マスキング）**:
  - プレビュー画面上をドラッグして四角く囲むだけで、白塗り（文字消去・修正用）または黒塗り（機密情報マスキング）が配置されます。
- **画像の新規アップロード埋め込み**:
  - 手元の社印やロゴ画像（PNG/JPG）をアップロードしてPDF上に追加挿入することも可能です。
- **完成後プレビュー確認**:
  - 「完成後プレビューで確認」ボタンを押すと、すべての変更が反映された仕上がりイメージを全ページ確認できます。修正があれば戻ってやり直し、問題なければ保存先を選択して新規PDFを出力します。

---

### 3. 📑 PDF結合（ドラッグ＆ドロップ並び替え ＆ ブロック一括移動）
- 複数のPDFファイルを1つのPDFにまとめます。
- 結合後のファイル名を自由に変更可能。
- 各カードをドラッグして直感的に結合順序を並び替え。
- **複数ブロック一括移動**: `Shift` キーやチェックボックスで複数選択したカードを、1つのまとまりとして一括ドラッグ移動できます。

---

### 4. ✂️ PDF分解（単票化 ＆ 一括通し番号命名）
- 複数ページのPDFを1ページごとの個別PDFに分解します。
- **柔軟な一括命名ルール**:
  - プレフィックス（例: `請求書_`）
  - 連番の桁数指定（ゼロ埋め3桁: `001`, `002`... など）
  - 開始番号の指定
- 奇数ページのみ、偶数ページのみの選択にも対応。
- 保存先フォルダを選択すると、フォルダ内に全ページが一括保存されます（ZIPダウンロードにも対応）。

---

### 5. 🔄 向きの変更（サムネイル回転 ＆ スキャナ裏面対策）
- ページごとのサムネイルを見ながら、[↺ 左90°] [↻ 右90°] [⇅ 180°] で回転。
- **便利な一括処理機能**:
  - **全ページ一括回転**（+90° / -90° / 180°）
  - **偶数ページのみ180°反転**（両面スキャナー取り込み時に裏面だけ逆さまになる現象をワンクリックで解消）
  - **元に戻す（リセット）**

---

## ⚠️ スキャン等で生成されたPDF（画像化されたPDF）についての注意点
紙の書類を複合機やスキャナーで読み取ったPDFは、文字情報を持たない「画像データ」として保存されている場合があります。
このようなPDFでは、文字データの直接選択・文字クリック式ハイライトは機能しません。

💡 **スキャン書類を修正したい場合の代替テクニック**:
- 文字を修正したい場合は、**「墨消し・白塗り」**で対象箇所を四角く隠した上で、**「テキスト」**ツールで上から文字を書き加えることで同様の修正が行えます。
- 「PDF結合」「PDF分解」「向きの変更」はスキャンPDFでも全く問題なくご利用いただけます。
